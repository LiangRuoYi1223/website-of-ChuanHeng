# 第二版：视口碎片修复与主要建筑细化

用户反馈的第一版视口截图存在碎片状表面，并指出建筑精细度不足。本轮保留第一版文件，生成第二版工程，避免覆盖用户已经打开且可能有未保存修改的场景。

## 第一版的具体问题

只读检查实际第一版工程确认：全部 3D 视口保存为近裁剪 0.01 米、远裁剪 30000 米，跨度比达到三百万。该范围会损失深度精度，使距离很近的地形、道路和窗片在透视视口中互相闪烁；这不是图片分辨率问题。[Blender 官方说明](https://docs.blender.org/manual/en/4.0/troubleshooting/3d_view.html)解释了此类显示限制。

道路还有真实网格错误：仅在边缘顶点取地形高度，却以较大的面连接。初始有限采样发现 100 个对象穿地、最深约 0.414 米；后续更完整的地形交片检查确认 295 个道路/水体中 110 个对象穿地，最深约 0.439 米。扩大道路偏移不能可靠恢复与地形的贴合，必须沿地形折线重新切分。

第一版建筑主要是原轮廓挤出与表面窗片。公开资料已经足以构建部分高低体量、柱廊与窗墙进深，但第一版没有落实这些，因而商学院与智华楼过于相似，一丹也缺少玻璃端部和竖肋。

## 第二版的实际修订范围

- 视口保存校园尺度裁剪范围、校园中心的正交初始视角，普通视口隐藏概览标签。校园整体使用 10–12000 米；查看极近的细节时可在 N → 视图中单独减小近裁剪，避免切掉眼前物体。
- 道路按原始 DTM 的每个三角形裁切；每个输出道路三角面只依附一个地形平面，再添加 0.15 米的显示厚度偏移。没有修改原 DTM。
- 主要地标使用有厚度的墙、柱梁、框架与凹入玻璃，替换在完整墙面前贴小窗片的做法；增加女儿墙和屋顶/露台栏杆。
- 商学院拆分两侧高翼楼、退台上部两层与低玻璃连桥，桥下开放并由实体立柱承托。两侧翼楼采用不同窗墙结构。
- 智华楼拆分五层高端块和较低长翼，保留开放庭院与底层柱廊。高端块具体地理角仍按照片估算。
- 理学院采用大面积幕墙、实体竖框、细梃和顶层矮窗带，保留原来的低翼/高塔分区。
- 工学院增加宽横凹窗、浅色底部墙带及坡屋顶边缘构件。
- 一丹图书馆增加橙面竖肋、多行错落凹窗与北端通高玻璃；窗行不当作楼层，仍按总四层组织。

## 精度边界

第二版已通过三阶段 Blender 验证和独立显示/几何检查。全部保存视口为 10–12000 米、初始校园中心正交视角；295 条道路/水体的 16,405 个三角面与原始地形求交后，55,694 个交片检查点没有穿地，清距约 0.15 米。实体窗框、玻璃凹入、桥柱与屋顶构件均存在三维网格。数值见 `build-validation.json` 与 `display-geometry-qa.json`。这是文件设置和几何验证，没有声称已经在用户显卡的当前窗口上复现并截图对照。

这轮提升落实的是主要建筑的体量与建筑构件，尚不能称为完整校园精细复刻。普通建筑仍较简化；逐窗布局、入口台阶、地形平台、室内、最终绿化和真实材质贴图还没有完成。约 30 米的全球预测 DTM 不提供校园实测台阶、道路与平台标高，不能通过加窗框或细分网格获得这些真实信息。

尺寸与部分高度分区仍按公开照片估算，来源和估算说明保留在输入与模型属性里。保留的顶层原始 WGS84 建筑轮廓共 113 个来源要素；叠层、退台或挑檐的构件不能据此说成新增真实独立建筑。
