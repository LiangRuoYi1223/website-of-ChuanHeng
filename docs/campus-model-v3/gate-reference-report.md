# 一号门与校名石精细建模参考

核查：2026-10-07（Asia/Shanghai）。本轮只取得/检查参考，不改 Blender 工程。所有照片用于形态与材质研究，没有作为贴图发布许可。

## 已视觉确认的三个对象

1. **一号门标志墙**：复用 [ICM 原始照片](https://icm.sustech.edu.cn/map/img/gate1.jpg)，原图2098×2796已实际查看。它是浅灰米色石材薄墙，顶缘略有弧度/高低变化，向门内一侧是深色竖向玻璃/金属凹槽。外侧有深灰绿色立体竖排校名，英文在左侧竖排；底部与黑色薄雨棚连接，雨棚下有瘦黑柱、门禁和小门房。它不是自然校名石。
2. **独立校名石**：总务官方 [校园景观页](https://gao.sustech.edu.cn/campus.html?lang=zh-cn)明确说明校名石正对一号门、周围时花至少每年更换六次。页面菜单的 [stone.png](https://gao.sustech.edu.cn/uploads/202009/stone.png)实际查看，是矮而宽的暖粉棕色粗面自然石，蓝绿书法校名，后方有几株高大棕榈和琳恩图书馆。原图仅240×160，不能精确临摹刻字与背面。
3. **二号门/主校门**：[2023启用新闻](https://newshub.sustech.edu.cn/html/202309/44367.html)图片已实际查看，是两座独立白色竖向门柱及中间开口，与一号门薄墙雨棚形态不同。本轮一号门不能借用该照片的门柱形态或尺寸。

高教研究中心 [2019研修班页面](https://cher.sustech.edu.cn/news/detail/33.html)本次直接取得中文正文和 [校名石合影](https://cher.sustech.edu.cn/wp-content/uploads/2019/09/2-1.jpg)；web解析器回的是英文空正文，原HTML中实际有合影及说明。1269×952原图已查看：宽横石体及三株棕榈在琳恩图书馆门前草地；后方是银灰错列横格栅与橙铜色通高开口。人物遮挡石体正面下半部，不能当完整扫描数据。

## 可落实构件与制作候选

| 构件 | 可靠形态 | 可用制作候选；米数均为照片估算 |
|---|---|---|
| 一号门墙 | 薄壁、弧形顶缘、灰米色石板、立体竖排字、深色侧槽 | 约宽6–8m、高6–9m、厚0.4–0.7m；不把现有9m称为官方尺寸 |
| 雨棚 | 深灰钢框、薄檐、下面可见细密横向梁 | 约高3–3.5m、深5–7m；主梁/次梁分开，檐板厚0.15–0.25m |
| 入口地面 | 灰色矩形石板、真实接缝、黄色盲道、低路缘、门禁 | 主铺装候选0.6×1.2m错缝；盲道宽0.3–0.4m、路缘高0.10–0.15m；不复制临时广告牌 |
| 校名石 | 暖粉棕粗面横石、缓圆肩、顶部略平且不规则、浅色石晶点、绿蓝字 | 宽6–9m、高1.6–2.3m、厚1.5–2.5m；只做近似外壳，不能称精确复刻 |
| 石周景观 | 草地/低花环、三株高大棕榈、周边乔木 | 花环用低灌木与季节小花，避免做成巨大坚硬花池；棕榈高度候选10–14m |
| 校内景观灯 | 深色细柱、浅米倒圆锥灯头 | 高3–4m候选；合影中可辨认，相应人行道优先补此轮廓 |

PBR候选：墙石非金属，roughness0.70–0.82，灰米白轻微石晶/纵向污迹；雨棚喷漆钢 roughness0.35–0.48、metallic0.15–0.30；校名石roughness0.78–0.90，暖粉棕底色、不规则浅/深矿物斑点，刻字另层略嵌入；铺装roughness0.85，毫米级颗粒和清晰接缝。参数是制作建议，不是材料厂商检测值。

## 地理关系与能否精确定位

- 一号门ICM点113.99450,22.59564仍是公开官方命名点，用于既有校门位置；它没有门墙端点、门房平面或测量精度声明。
- [2020官方桥梁图](https://newshub.sustech.edu.cn/uploads/full/2020/10/281603863115983152.jpg)已实际查看，一号桥对应一号门，跨大沙河接北岸理学院/校园道路。既有 OSM context 中一号桥 way 带 `bridge=yes/layer=1`，建模应与河面分层，不把普通贴地路直接横铺过河。
- 总务景观页的SVG含1920×2713平面设计底图，原SVG及其中嵌入JPEG已保存并查看。它标出一期图书馆、理学院、主入口与广场、大沙河等，但**没有明确校名石标注与地理控制点，也没有可验证石体端点**。不能仅凭图中圆点给校名石宣布精确坐标。
- 合影确认校名石在琳恩图书馆可见的主立面/大开口前方草地；相对于一号门是入校后、河桥北侧、向琳恩方向。图库与地图都缺少相机北向/坐标，因此本轮只可把石体定位标记为 `approximate_photo_and_map_relationship`。若将其放入模型，应保留可独立挪动的集合和估算标记；不以一号门墙体位置代替石体。

## 公开 VR 可用性与核查陷阱

学校 [VR入口](https://sustech.edu.cn/vr.html)指向 [720云校园作品](https://720yun.com/t/e7vkOhpy5fy?scene_id=88047861)。本轮直接取得入口及作品公开HTML；作品元数据 createDate1603168658、updateDate1647334864，初始状态明确 `storageExpired=1/product.expired=1`。学校链接真实存在，但没有声称已观看有效全景或完整高分辨率场景，不绕过过期存储状态。

景观页“一号门”栏目中的两张背景照片实际是宿舍花坛、第二科研楼步道，而不是校名石。它们已下载/查看并按实际场景更名为 `gao-campus-flowerbed.jpg` 与 `gao-campus-research-building.jpg`；不会仅凭栏目标题错误匹配校门。
