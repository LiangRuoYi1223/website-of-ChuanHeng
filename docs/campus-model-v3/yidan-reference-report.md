## 构件比例建议（全部为照片估值）

| 构件 | 可用于本轮的尺寸/规律 | 实现重点 |
|---|---|---|
| 橙红面板 | 粗糙度约 0.45–0.65；主色用偏陶土的橙红，轻微分片色差 ±3% | 不用单色高饱和塑料材质；不把 JPEG 直接铺上墙 |
| 外墙竖肋/折边 | 节距约 2.3–3.2m、宽 0.10–0.18m、出墙 0.12–0.25m | 墙面高光阴影的连续竖节奏比增加随机窗更重要；随局部墙高截断 |
| 橙墙窗 | 常用长窗宽约 1.6–2.4m、高 0.40–0.70m；少量合并竖窗高 1.4–2.2m | 是错列、相邻成带的短窗，宜固定窗口表/确定性规则。保留大片橙色实墙，不铺满整个立面 |
| 窗带 | 照片呈上下两个明显密集带，中间及顶边有稀疏窗；各带内部有半窗高错位，部分多层高窗聚成簇 | 低密集带约本体高度 0.20–0.38，高密集带约 0.58–0.78；仅作为起始布置，检查渲染后修正，不能称实测窗表 |
| 南玻璃端 | 大约 5–6 个竖向主要分格；细分格/横框进一步拆分 | 玻璃后加楼板边、少量室内阴影层，避免不透明纯蓝板；框宽约 0.06–0.12m |
| 东侧深框/折片 | 约 1.1–1.8m 重复节奏、深度 0.30–0.65m，竖框细 | 轮廓与遮阳阴影要可见，宜实体做，不只画纹理；方向与真实墙边切向一致 |
| 屋顶栏杆 | 高约 1.05–1.15m，细立杆直径 0.02–0.035m，节距 0.12–0.18m | 远景可合并网格或贴图，近景看清黑细栏杆和实际投影 |
| 共用白色连廊 | 净空约 4–5m，檐厚约 0.35–0.55m、通道宽约 4–6m | 不是实心裙房箱体；底下应通透，白圆柱直径约 0.40–0.55m |
| 圆柱节距 | 约 5–7m，采用公共连廊真实走向 | 设计方原图中柱身很细，不使用粗方柱墙；局部侧阶梯边还有双柱 |
| 入口宽台阶 | 单级高 0.14–0.17m，踏面深 0.30–0.36m；另有草带分隔的侧阶梯 | 二层主入口与平台必须相接，楼梯末端落在铺装/平台，不能浮空穿地 |
| 院落、白露台 | 使用既有中心基座真实轮廓和 7 个院落孔洞；低灰白栏杆、铺装接缝和小草带 | 不填平院落，不把场地做成无依据巨大圆形平台 |

## 本轮近景应优先做的部分

1. 正确南端玻璃、东长侧折片和西侧橙壳三种立面，修正南高北低屋顶。
2. 窗户真实凹入、外框和橙面板折肋；玻璃具有反射和内部暗层，而非贴在实体墙上。
3. 屋顶栏杆、入口字牌、底部白玻璃带，少量可透过玻璃看到的楼板/柱，不要求室内全模。
4. 白色公共连廊、圆柱、宽阶梯、平台栏杆、院落地面，让图书馆与地形发生可信连接。
5. 邻近树群体现高低、深浅、透光差异；镜头不能仅用空草地包围图书馆。植物种类/精确栽植点未测绘，视为景观重建估算。
