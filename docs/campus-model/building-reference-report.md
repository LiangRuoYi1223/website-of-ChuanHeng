# 南科大校园建筑体量参考核对

核查日期：2026-10-05 至 2026-10-06（Asia/Shanghai）。本报告支持在 GEDTM30 预测裸地基底上制作可辨认的校园建筑第一版。楼名和部分楼层/高度有官方依据；其余米制高度是制作候选，不能称为实测、竣工测绘或精确复刻。

## 层数、高度与第一版候选

所有建筑高度均指相对于各自建筑基座的高度，不是EGM2008海拔。先用真实足迹与DTM定位，再对单栋形成平整基座；公开30米DTM不足以恢复校园台地和每个入口标高。

| 建筑 | 已核实依据 | 第一版建议 | 证据限制 |
|---|---|---|---|
| 理学院 | [总务期刊2022](https://gao.sustech.edu.cn/uploads/202202/15103704_32883.pdf) PDF第5页（印刷05–06）：地下1层、地上5–9层；原页已视觉查看 | 拆为5层低翼和9层高塔，暂用约25米/45米体量候选；保留庭院和翼间高低关系 | 本次未核实竣工米制高度。政府规划PDF搜索索引出现49.0米，但原文件未成功取得，不能将其作为已验证高度。 |
| 工学院南/北 | [工学院官方启用新闻](https://coe.sustech.edu.cn/News-Detail-id-271.html)：南9层42.3米，北10层46.8米 | 用42.3/46.8米最高体量控制，沿翼段形成下降屋顶/檐线，不能统一平顶 | OSM南楼10层与官方9层冲突，官方优先；公开数字非现场复测。 |
| 商学院 | [商学院2021建设新闻](https://business.sustech.edu.cn/web/news_detail.php?id=25)：地上5层、地下2层；总务期刊再次确认 | 主翼5层，暂用约23米；中央连廊和露台做明显较低层次 | 23米是制作估值。不同报道建筑面积口径不同，不用面积反算足迹。 |
| 智华教学楼 | [2022启用新闻](https://newshub.sustech.edu.cn/html/202208/42555.html)及[官方教室导览](https://guide-cr.tao.sustech.edu.cn/sj/)均确认5层 | 主体5层，暂用约23米，保留高端块/低翼/中央庭院 | [2026校友讲座](https://aa.sustech.edu.cn/study/noticed/id/2998.html)明示智华楼原第三教学楼；[2026-01-12揭牌新闻](https://newshub.sustech.edu.cn/html/202601/47208.html)确认1月10日冠名揭牌。 |
| 一丹图书馆 | [2020开馆新闻](https://www.sustech.edu.cn/10th/news/39486.html)：四层、9010平方米；[官方空间布局](https://lib.sustech.edu.cn/kjbj/list.htm)列出一至四楼 | 用4层组织，约20米体量候选；玻璃端头与橙色外壳围合中心平台，屋顶要渐变高低 | OSM building:levels=5与官方四层冲突，官方优先；不要数错落开窗的行数推断楼层。 |

理学院、商学院、智华和一丹的暂定米数应在模型属性中标记 `height_estimated=true`，以后用竣工图、测量或可靠标注替换。

楼层校准应明确覆盖 OSM 标签：理学院整体 `building:levels=5` 改为官方确认的5–9层分区；商学院 OSM 8层采用官方5层；工学院南楼 OSM 10层采用官方9层；一丹 OSM 5层采用官方4层。理学院高塔在官方斜鸟瞰和外景中可辨认，但这些照片没有北箭头/拍摄坐标，本次不能独立证明其位于哪个地理角。已实际查看根代理取得的 `sustech_satellite_esri.png`；北向上原图1792×2048中，Science标签约在像素753.4,1733.8，ICM数学系7楼点113.99453,22.59657约在804.3,1760.9。它们可帮助对应卫星可见屋顶，具体高度分区仍应标记 `height_partition_estimated=true`，不能将部门楼层点当作9层塔的完整边界。卫星来源、范围、校验与版权见根代理的 `satellite-source.json`，影像拍摄日期未核实。

## 其他地标

- 一号门：ICM自定义点113.99450,22.59564，南侧学苑大道入口；已查看 `gate1-icm.jpg`。可辨认特征是浅色石材弧形顶缘标志墙、竖排校名与英文、黑色水平雨棚、门禁小体量。候选约6–8米墙高，只是照片体量估计；本参考不能证明独立天然“校名石”的准确位置/形状。若需要入口标志，可先照此墙体建模。
- 琳恩图书馆：ICM113.993372953,22.597928963；与一丹明确为不同楼。实景为银灰模块格栅、略弧形长体、橙色贯通游廊，适合低层体量和连桥。
- 南科大会堂/会议中心：ICM113.991775671,22.595571343，校园西南侧河湾；实景为白色弧形长翼、通高竖向幕墙，顶层/屋顶呈较轻开口围合，不能用圆顶礼堂替代。
- 润杨体育馆：ICM113.999148140,22.60470996，运动场旁；实景为不对称灰色大悬挑折面屋盖、斜向支撑与玻璃底部，优先做屋顶形态。
- 未来广场/大草坪、中心古榕树、大沙河和校内溪流能帮助识别楼群。树木、铺装、道路细节为第一版制作，不作为30米DTM已经存在的几何。
