# 活动报名费用实施计划

**目标：** 后台活动编辑设置人民币报名费用，前台报名处及缴费窗口展示同一金额。

**方案：** 沿用活动 JSON，新增可选 `registrationFeeCents`（整数分）。元输入按十进制字符串精确转换；留空未知、0免费、正数显示两位小数。旧记录不自动填金额，既有缴费、报名及保险流程保持原规则。现有管理员与并发保护沿用，无需数据库迁移。

**技术：** 现有 React、Vite、Supabase 内容接口与 Node DOM 测试。
