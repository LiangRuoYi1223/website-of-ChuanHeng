# 前台登录入口 12 小时核验 Implementation Plan

**Goal:** 网站前台“正在确认登录…”及登录入口沿用后台同样的标签页内存核验规则，切回页面、站内切换和打开移动菜单保留已登录显示与用户名。

**Architecture:** 独立前台会话 store 供桌面与移动导航共用。首次服务器核验后固定 12 小时复用，不写浏览器持久存储；过期、明确账号信息变化时后台核验并保留同账号显示。后台既有管理员缓存与业务服务端鉴权保持原有职责。

## Requirements and boundaries

- 前台允许普通会员；管理员降级保留会员身份但立即移除管理入口，升级必须服务器确认。
- 退出/空会话/换号/匿名化立即撤销旧账号显示；不同账号及不同登录代次的迟到身份/资料结果不复用。
- focus/pageshow/visibility 只做轻量会话恢复；同账号有效期内不重复 getUser 或刷新用户名，不显示核验等待。恢复错过的退出/换号事件仍需工作。
- 同标签页的桌面、移动导航及路由共用请求；账户资料更新独立刷新用户名，不先清空当前显示。
- 首次及后台身份核验均有 15 秒超时；真实报名、个人设置、上传等操作仍使用现有服务端鉴权。
- 不更改登录表单、邮箱验证、数据库或敏感业务，不提交既存 KML 计划或 ignored 产物。
