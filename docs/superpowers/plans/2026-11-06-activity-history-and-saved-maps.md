# 活动分类、精选路线与静态地图

本轮要求已由用户直接确定，延续现有风格，不更改正式记录身份或历史快照。

- 活动保留报名状态分类，新增单日徒步、重装徒步、讲座活动、攀冰；旧类型原样兼容。
- 活动编辑可明确选择显示到大事记，默认不选；只有真实已发布且已经结束、时间完整的活动入选，最新在前，链接详情。
- 关于页只保留管理团队与领队两个成员部分，删除首屏“认识川衡”按键。
- 路线编辑可明确选中精选，默认不选；路线库和首页读取同一真实精选标志。路线库取消距离及爬升筛选，指标继续显示。
- 用户已选择“只保存一张覆盖路线的底图图片”。授权上传时从 Protomaps 官方开放 PMTiles 归档按区域读取必要真实要素生成被动 SVG，存入 track.basemap，记录范围、投影、实际归档、版本、来源、许可、时间。活动选择路线继续冻结当时快照。
- 访问路线/活动只读取已保存图片并叠加原轨迹，不实时取在线瓦片；旧路线在路线管理补图，失败保留原路线，不自动改写历史活动。
- 已实际生成的大南山公共区域图作为网站本地资源提供；只对无底图且所有实际点被覆盖的旧轨迹展示参考背景，不匹配名称/ID，不覆盖已有但失效底图，不改写数据。
- 地图生成沿用同源及可信领队/管理员验证；限制面积、要素/坐标/响应及图片大小、请求时间，取消和迟到响应不得覆盖当前编辑。

验证对应选择器和真实页面/编辑器回归、静态图安全与地理对齐、上传保存与活动快照、生产 Worker 实际运行时认证和出站请求；提交前全套测试和正式构建，部署后匿名访问与静态文件一致性检查。网络联调与实机视觉检查的范围单独如实记录。
