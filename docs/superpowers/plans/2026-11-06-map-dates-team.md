# 地图底图、活动日期与团队分区 Implementation Plan

**Goal:** 轨迹默认显示真实地图，活动起止显示到天、报名起止显示到分钟，关于页面团队区域改为管理团队/领队。

**Architecture:** 默认 Leaflet 底图改为 OpenStreetMap Standard，保留自定义 HTTPS XYZ 与署名配置；只请求当前视口，保留正常缓存和 Referer。底图就绪后显示可交互地图，失败保留真实轨迹及明确重试入口。日期仅改显示层，真实时间戳、报名窗口及清理逻辑不变。团队沿用现有两栏标签版式，不填造人员。

## Tasks

- [x] 地图：默认来源及署名回归先 RED；真实 Leaflet DOM 验证加载成功/失败/重试；实现并核对少量服务瓦片可达性。
- [x] 日期：增加北京时间日期格式，活动起止及活动列表/侧栏/个人活动记录只显示年月日；报名字段继续分钟，未知旧记录不补造；对应回归 RED→GREEN。
- [x] 团队：现有三标签改为“管理团队”“领队”，配套介绍与空状态，不改真实成员记录。
- [x] 全套测试、正式构建、独立审查；沿用此前授权同步 GitHub 和发布，核验公开入口/资源及回退点。

## Constraints and findings

- 原实现仅接 OpenTopoMap，12 秒无瓦片回退黑底坐标；外部瓦片失败不能伪造地形或清除真实轨迹。
- 2026-11-06 本机少量惠州样例通过系统默认网络路径：OpenTopoMap z13/z15 约 6.7/7.9 秒，OSM Standard 约 0.5/1.5 秒，均 PNG 200。不能由这组数据断言所有用户网络可达或原服务停止。
- OSM 官方政策：https://operations.osmfoundation.org/policies/tiles/ 。使用无子域 HTTPS、可见来源、有效 Referer 和浏览器默认缓存，不批量预取/提供离线下载，不添加代理或 API 密钥。
- 保留既存未跟踪 KML 计划；不迁移数据库，不读取真实报名、会员或缴费资料。
