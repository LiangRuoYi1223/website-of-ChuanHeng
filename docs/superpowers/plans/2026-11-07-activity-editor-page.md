# 活动独立编辑页实施计划

**目标：** 活动从弹窗编辑改为独立页面，桌面左侧编辑、右侧即时预览；先交付本地页面，用户确认前不部署、不写云端。

**设计：** 扩展既有 React/Vite 后台，沿用黑白、品牌橙和原始徽章。新建地址 `/admin/activities/new`，编辑地址 `/admin/activities/:id/edit`，本地预览保留 `?preview=1`。窄屏切换编辑与预览。复用公开活动正文渲染器，避免预览和公开页面使用不同文案。

**内容：** 在活动 payload 新增 `pageContent`，介绍标题、正文、提示框，行程标题、说明与任意步骤，装备标题、说明与任意模块，安全标题、条目、补充说明全部可改。列表支持增删与上下移动。缺失字段兼容旧页面文案，显式空内容不得被默认值补回。纯文本渲染，保留换行。

**约束：** 不迁移数据库，不改变活动路线快照、只读统计、报名时间窗口、费用、身份校验或并发保护。仅使用浏览器草稿作本地演示，不创建真实活动记录。现有未跟踪文件保留。
