# 活动侧栏分区切换设计

用户在 localhost 对比折叠、整卡滚动和分区切换后，选择「分区切换，排位常驻」。本次按选定预览实施，保留官网黑白与品牌橙。

## 选定行为

- 桌面活动侧栏继续吸附，卡片限制在可用视口内。顶部精简展示里程、爬升、难度、地点与活动时间。
- 「活动资料」「报名详情」两个页签共享一个可滚动内容区，支持鼠标和键盘切换。
- 底部持续展示本人的入选/候补/缴费状态、排位/名额与主要操作。详细说明、四个时间和较长缴费通知进入中段。
- 手机使用底部简短报名条，点击展开模态面板；关闭、Escape和登录返回报名锚点均可用，焦点回到入口。
- 超短视口和放大时允许必要的滚动，保证所有操作可到达，避免隐藏或裁切。

## 实现边界

只挂载一个报名状态组件，两个页签与手机条读取同一身份和报名记录。切换页签不得额外报名或重置操作。原有服务器排队、身份绑定、防重复提交、退出重报及候补提示继续有效。未知指标和旧记录日期不补造。

变化仅用于活动详情，不改变路线和资讯的侧栏。无需数据库迁移、权限变化或生产示例数据。

## 备选比较

折叠版可减少信息，但完整资料需要展开；整卡滚动版保持原顺序，但报名仍在底部。选定的分页版将长资料分开，同时保留报名入口。

## 验证

DOM交互覆盖页签、报名状态/变更、身份切换、锚点及移动面板；执行全套测试和正式构建。浏览器若受控工具无法连接，明确记录未完成实机视觉验收，不以DOM测试代替实机结果。
